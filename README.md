# TrailyTail — website

Outdoor gear reborn for dogs. https://trailytail.com

## Structure
- `index.html` — one-page site (EN / UA, language switch built in)
- `assets/` — photos, logo (SVG), social preview image
- `favicon.png`, `apple-touch-icon.png` — browser and phone icons
- `CNAME` — custom domain for GitHub Pages

## Editing texts
- English texts are in the HTML itself.
- Ukrainian texts are in the `uk` block inside the `<script>` at the bottom of `index.html`.
- Link `https://trailytail.com/#ua` opens the Ukrainian version.

## Replacing photos
Put new photos into `assets/` with the same names (`hero.jpg`, `workshop.jpg`) or update the paths in `index.html`.
